## The Goldmine Question

**What makes ChatGPT actually choose one ecommerce site/product/merchant over another?**

OpenAI says:
- Relevance to user's intent
- Price, reviews, ease of use
- Availability, quality
- Whether merchant is maker or primary seller
- Product recommendations separate from ads
- Direct product feeds for fresher information

**The old playbook:**
```
keywords → backlinks → click → landing page → convert human
```


## The Eight Opportunities

### 1. House as Product Graph

```
ADDRESS
├── Fuse board
├── EV
├── EV charger
├── Boiler
├── Heat pump
├── Solar inverter
├── Battery
├── Smart meter
└── Appliances
```

One £80 EV-install lead becomes **10 years of transactions**.

### 2. Home Electrification OS

```
"Can you make my house cheaper to run?"
    ↓
property → energy usage → car → tariff → roof → heating
    ↓
upgrades → installers → grants → ROI → financing → schedule
```

### 3. Trade Procurement Agent

```
Jim has 3 Zappi installations this week.
He's short two RCBOs and 18m of cable.
CEF has them locally at £X. Order?
```

**Agentic B2B commerce.**

### 4. Asset → Failure → Part → Technician

```
identify boiler → interpret fault → retrieve asset record
→ determine likely parts → check warranty
→ find qualified engineer → reserve part → book engineer
```

**Service + product combined.**

### 5. Commercial Compliance Agent

```
asset registry → required inspection dates
→ book contractor → collect certificate
→ find deficiencies → approve repair
→ order parts → invoice
```

**Recurring, predictable, high-retention demand.**

### 6. Garage Doors / Gates / Windows

Bravi (YC) started here because:
- Quoting is complicated
- Installers lose leads
- Product knowledge matters
- Software is terrible

### 7. Compatibility Commerce

```
"replacement for Grundfos XYZ"
"filter for this ventilation unit"
"cable for this charger + car"
"door seal for Bosch model..."
```

**Where conversational agents beat keyword search.**

### 8. Scan Your House

```
photo boiler → photo fuseboard → photo washing machine label
    ↓
manufacturer → model → serial → age → manual → parts
    ↓
home asset wallet
```
