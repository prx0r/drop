## The Key Insight

This is not dropshipping.

This is a **new distribution layer forming between intent and fulfilment**.

### Google Validated the Behaviour

Google announced that for home repair, users can ask Search to call businesses on their behalf. The journey is changing from:

```
user → agent → providers → structured comparison → booking
```

- 888 service categories
- AI-native directory
- Provider discovery, structured pricing, real-time availability
- MCP, booking, Stripe payment
