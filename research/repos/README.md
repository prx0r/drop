# Reference repositories

These were identified as high-value code resources. The build environment could not resolve github.com from the local container, so they are not vendored into this ZIP.

```bash
git clone https://github.com/google-marketing-solutions/merch-intel.git
git clone https://github.com/google-marketing-solutions/feedgen.git
git clone https://github.com/google-marketing-solutions/feedx.git
```

- Merch Intel: Merchant Center Market Insights + Ads performance -> BigQuery/Looker.
- FeedGen: generative feed optimization.
- FeedX: item-level feed experiment design/analysis.
