# Copyright / archive note

This bundle does **not** copy full copyrighted blog posts, YouTube transcripts, Reddit threads, or course materials. It contains source URLs, normalized factual observations, short summaries and schemas. Open the original source for the full work. Official Google documentation/code links are indexed separately.

The environment used to build this bundle could not directly clone GitHub over the container network, so the Google reference repositories are linked rather than vendored. Clone commands are in `repos/README.md`.
