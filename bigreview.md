## "Annoying to buy" is the key

### Good annoyance (opportunity)
- "I don't know which one I need"
- "Every retailer explains this badly"
- "Does this work with my existing equipment?"
- "What's the difference between these models?"
- "Nobody stocks the full range here"
- "All the decent guides are in English but I'm Finnish"
- "This shop has it, but I don't trust the site"
- "Shipping/returns aren't clear"
- "Which accessories do I need?"

### Bad annoyance (structural disadvantage)
- Requires medical advice
- Import regulations are horrible
- It breaks constantly
- Everyone returns it
- Customers need it tomorrow
- Installation requires licensed professional
- Amazon sells it below our landed cost

## Optimize for boring £150–£1,500 products

Research-heavy, specification-heavy, fairly standardized, non-perishable, non-fashion-sized, not excessively fragile, low support catastrophe risk, accessories available, model numbers exist, supplier can ship directly, customer isn't purchasing purely on price.

> "I have £600 and need the right version of this somewhat boring thing."

That buyer is valuable.

## Supplier evolution stages

### Phase A — Validation supplier
Make the store operational without capital or dealer negotiations.
UK: Avasam. EU: Syncee, AppScenic (2-6 day EU shipping).

### Phase B — Direct supplier
Once we see impressions → clicks → carts → orders, approach manufacturer/distributor directly.

### Phase C — Selective dealer
Better margin, protected brands, preferential pricing, territory access, local warehouse, live inventory feed, exclusive bundles.

> **Easy supplier gets us into the experiment; difficult supplier becomes the moat.**

## The 14-dimension opportunity rubric

| Dimension | Question |
|---|---|
| **Existing demand** | Are people demonstrably buying it? |
| **Purchase friction** | What makes buying it annoying? |
| **Search intent** | Are there exact-model/bottom-funnel queries? |
| **Local merchant quality** | How many genuinely good sellers exist? |
| **Supplier ease** | Can we fulfill one order tomorrow without inventory? |
| **Shipping** | Can we match reasonable local expectations? |
| **Contribution** | Is there enough £ left before ads? |
| **Price competition** | Are identical SKUs brutally compressed? |
| **Amazon/manufacturer** | Can we plausibly beat or differentiate? |
| **Advice value** | Can expertise materially change purchase choice? |
| **Accessory potential** | Can basket size/margin expand? |
| **Localization gap** | Does another market have a visibly worse experience? |
| **Free validation** | Can Google/query pages give us signal before spending? |
| **Supplier upgrade** | Path from easy → direct/selective dealer? |
