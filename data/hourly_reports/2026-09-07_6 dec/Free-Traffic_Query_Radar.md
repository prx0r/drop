Local wording:
- `Davis Vantage Vue vs Vantage Pro2`
- `Davis Vantage Vue eller Vantage Pro2`

Observed composition: Prisjakt + multiple Norwegian merchants/distributors, but little obvious independent decision-first content. This is attractive because **commerce is dense enough to prove purchase reality while comparison support is weak enough to differentiate**.

Cheap probe: one Norwegian comparison page with model/variant matrix and live-stock links.

ADVANCE if Search Console exposes exact-model and comparison variants. KILL the content thesis if the page receives no non-navigational exact-model impressions after a sufficient indexing/internal-linking window.

### 2) Norway — Davis replacement parts / winter

Local wording:
- `Davis Vantage Vue servicekit Norge`
- `Davis Vantage Pro2 reservedeler`
- `Davis regnmåler varmer Pro2`
- `Davis vindmåler Vantage Pro2`

This may be more economically useful than generic weather-station content. Prisjakt already exposes service kits, rain collectors and anemometers; BestMarin has a Pro2 rain-gauge heater with live stock; Flak exposes a broad replacement ecosystem. The negative space is compatibility/lifecycle navigation, not product existence.

Cheap probe: model-indexed accessory matcher + exact SKU pages only for stock you can actually sell.

### 3) Norway — WeatherLink system choice

Local wording:
- `Davis WeatherLink Console Norge`
- `WeatherLink Console vs WeatherLink Live`
- `Davis værstasjon app WeatherLink`

Norwegian sellers stock the Console and bundle it with Vue/Pro2, but practical system-choice guidance is fragmented.

Cheap probe: compatibility map from base station → console/data option → remote/app/export outcome.

### 4) Norway — hytte / remote-property use

Local wording:
- `værstasjon hytte Davis`
- `Davis Vantage Vue hytte`
- `værstasjon for hytte med app`

This is a weaker signal than exact-model/parts, but it directly supports the differentiation thesis in the current blueprint: win on remote property, winter, maintenance and support rather than merely stocking Davis.

Cheap probe: “Værstasjon for hytte: Vue eller Pro2?” with winter, siting, power/data and replacement-parts guidance.
