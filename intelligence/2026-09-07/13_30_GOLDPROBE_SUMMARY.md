## Report 3: Agent Discovery Alpha

### Key Findings:

1. **Shopping queries are commerce-page-heavy**
   - 58,846 ChatGPT shopping citations analyzed
   - 67.5% were commerce pages
   - Two independent Shopify stores out-cited Amazon ~10× in their niches

2. **Reddit is NOT essential for AI shopping visibility**
   - Reddit: 0 / 58,846 ChatGPT shopping citations
   - 0.5% across 207,297 total citations
   - YouTube was the top community source

3. **Citation is NOT recommendation**
   - 61.7% were "ghost citations" (source linked but brand never named)
   - Only 13.2% were both cited and mentioned
   - ChatGPT cited in 87% but mentioned brands in only 20.7%
   - Gemini showed inverse: mentioned brands in 83.7% but cited only 21.4%

4. **LinkedIn is structurally important for B2B/professional queries**
   - LinkedIn appeared in 11% of AI responses on average
   - 14.3% for ChatGPT Search, 13.5% for Google AI Mode
   - Long-form articles and original posts dominated

**Net belief update:** The discovery layer is not one universal "authority graph." It is:
```
query class → engine-specific retrieval corpus → source eligibility → citation → brand/entity mention → recommendation slot → click/transaction
```

   - Decision friction exists but is mostly solved

   - Real connector/network/adapter complexity exists
   - Strong retailers already publish detailed compatibility
   - Merchant whitespace not yet proven

4. **UK — Truma CP Plus control-panel replacement is FALSIFIED**
   - Specialist caravan merchants already state constraints clearly

**New rule:** Replacement markets become interesting when the compatibility object is:
```
STATEFUL LEGACY SYSTEM → SAFE SUCCESSOR BUNDLE
```
Not MODEL → SKU, but board revision + controller generation + firmware/network generation + safety accessory state + desired functionality.

## Cross-Report Synthesis

### What's Working:
1. **Norway radon remediation** — objective trigger, structured documentation, verification outcome
2. **Finland Harvia sauna migration** — stateful compatibility, large installed base
3. **Ireland lead-pipe replacement** — grant-funded, structured documentation
4. **Wix Bookings × Google** — live supply state synchronization

### What's Falsified:
1. **Norway Mitsubishi remotes** — merchant gap already closed
2. **UK Truma CP Plus** — specialist merchants already solve it
3. **x402 adoption metrics** — largely fictitious

### What's Open:
1. **Norway cabin water systems** — large installed base, compatibility pain
2. **Finland heat-pump lifecycle electronics** — not remotes, but boards/sensors
3. **Norway/UK marine transducer migration** — complexity proven, merchant gap unproven

### The Pattern:
The strongest opportunities are where:
- Objective failure/compliance trigger exists
- Structured diagnosis is possible
- Formal qualification/documentation required
- Geographically limited provider set
- High enough job value
- Post-work verification possible

The weakest opportunities are where:
- Model→SKU compatibility is already explicit
- Specialist merchants already publish good technical guidance
- OEM provides direct resolution
